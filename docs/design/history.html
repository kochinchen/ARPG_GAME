專案回顧 · 地牢冒險 Dungeon Adventure · 2026 年 9 月

先拆解，做出 MVP，
再一層一層補強

一款 Diablo 式 2D 等角 ARPG，用 TypeScript + PixiJS + Vue 從零開始寫。這頁整理這次開發的方法論，以及從架構文件到可攜版遊戲包的實際過程。

20 個 commit M0～M9 共 11 個 Milestone（含臨時插入的 M7.5） M7 完成時 260 個測試通過，目前 999 個 核心 MVP 用時 2 天
方法論

五個做法

先設計，再寫程式

第一個 commit 以 ARCHITECTURE.md 為主：技術選型比較、座標與更新頻率原則、模組邊界、依賴方向，以及 M0～M9 路線圖。

每個 Milestone 都有 Goal / Classes / Dependencies / Acceptance / Test

規則交給工具檢查

架構規則寫進 CLAUDE.md，再用 dependency-cruiser、無 DOM 的邏輯 tsconfig、UI 直接寫入掃描測試自動擋下違規。

AI 寫錯會在 npm run lint / npm test 被抓到

每一步都能實際玩

每個 Milestone 完成後遊戲都能操作，通過驗收和測試才進下一個。

測試數從 28 一路累積到 260

高風險系統先寫規格

存檔與三段 Combo 先寫獨立規格，把重新整理刷寶、關分頁、多分頁等漏洞列清楚再實作。

SAVE_SYSTEM.md · COMBO_SYSTEM.md

文件跟著程式更新

完成時補上「狀態／實作細節」，記下和規格不同之處與原因；發現的問題寫給後面的 Milestone。

例：M3 發現重生死亡循環 → M7 規定存檔點 7 格內不放怪

更名「地牢冒險 Dungeon Adventure」與難度大改8412715

標題畫面改為英文標題 Dungeon Adventure、副標「地牢冒險」。怪物強化（第 1 → 35 層逐層提高）：一般怪與精英 HP ×1～8、魔王與 31～35 層的魔王 HP ×1～20、攻擊 ×1～4、特殊技能的圓形 / 扇形範圍 ×1.5～3（普通攻擊與直線招式不變）、經驗 ×0.7；第 1 層與原本相同，越往深層越強（第一版從 ×3 / ×8 / ×2 起跳，前期太難，已調降）。藥水回復 35% → 25%、冷卻 1 → 2 秒；技能樹「血之汲取 / 魔力汲取」每級 0.2%，滿級 1%。

GitHub Pages 另外放上設計文件（docs/design/）與 README（be78bea · 67101a1）。修正傳奇「分裂」效果沒有作用：分裂的箭與小火球原本從被打中的敵人中心生成，第一步就又打中同一個敵人而消失。現在從敵人身體邊緣飛出、不會再打同一個目標；並加上檢查，所有 50 件傳奇 / 神話效果的技能條件都至少有一個技能能觸發。

換裝：裝備直接穿在主角身上74b2140

武器、頭盔、盔甲、靴子依裝備改變外觀：四個部位各 8 階造型，外加 15 件橘 / 紅防具專屬外觀。詞綴決定主題：元素、吸血、法術等詞綴改變顏色、寶石、發光符文與光芒；防禦類詞綴讓裝備變厚重，敏捷類長出翅膀，荊棘加上尖刺。武器微光也改用主題色。

先畫物品圖示與換裝樣張確認外觀，再放進遊戲。外觀完全由裝備資料推導，存檔格式不變；換裝後主角面數只多約 7%。

盾牌、金幣用途、角色預覽72cd75f存檔 v12

新增盾牌欄位：8 階盾牌與 3 件橘、3 件紅，只能搭配劍或斧，主打格擋（最多 50%，格擋時傷害 -60%）、防禦與抗性，橘紅效果在格擋時發動。金幣新用途：商人的詞綴重鑄（越重鑄越貴，橘紅只重擲固定屬性的數值）、一鍵賣出白 / 白＋藍 / 白＋藍＋黃、技能點與屬性點洗點（費用隨等級提高）。角色頁旁加上大尺寸人物預覽（可轉向），選單可關掉頭盔外觀。

人物預覽一開始用獨立的 PixiJS 畫布，反覆開關背包後瀏覽器丟掉了遊戲畫面的 WebGL 環境（畫面變黑），改成由遊戲畫面的 Renderer 直接畫在預留區域。

物品圖示與手套外觀64f7bf4

背包、裝備欄、商人貨架與拆解區的武器、頭盔、盔甲、手套、靴子、盾牌改用圖示：直接用遊戲裡的裝備模型投影，所以詞綴主題、稀有度染色與橘 / 紅專屬造型都和身上看到的一樣；背景是稀有度光暈，元素等主題加上粒子。戒指、護符、藥水也有圖示（寶石換成詞綴主題色；橘為金、紅為深淵材質）。每一格都是「小圖示 + 稀有度顏色邊框」，橘、紅邊框帶光暈，紅色會脈動。手套也穿到主角身上：8 階造型與 5 件橘 / 紅專屬外觀，護手換掉皮護腕。

手套在地圖上只有幾個像素，所以指節甲、爪、尖刺、寶石只在放大（角色預覽）時才畫，遊戲畫面只換護手與手套的顏色。

拿武器的姿勢、背包格放大、怪物追擊0f307ef

平常（待機、走路）拿武器的方式依種類不同：斧柄與前臂垂直、斧頭朝前；法杖杖頭往前傾；弓直立在身前、弓背朝外；劍不變。攻擊時從平常的角度轉到招式的角度。背包格放大到 1.5 倍（面板跟著變寬），每一格的邊框都是稀有度顏色。一般怪物放棄追擊的距離從離出生點 14 格加大到 28 格；走回家途中被打會回頭追擊，被打中後 4 秒內超過距離也不放棄。

原本背包格的邊框被面板的格子樣式蓋掉（同名的 CSS class），所以只看得到灰色細框。怪物原本離家太遠就走回出生點、途中不理會攻擊，玩家可以站在範圍外把牠射死。

吸血 / 吸魔硬上限0f307ef

技能「血之汲取 / 魔力汲取」1～5 級改為 +0.1%～0.5%；其他每一個來源最高 +0.3%：一般詞綴 0.1%～0.2%、強屬性 0.2%～0.3%（不再隨階級成長），8 件傳奇 / 神話的吸血屬性、「低血量時吸血」、「近戰命中回復傷害的一部分」都降到 0.3% 以內；「近戰暴擊時回復傷害的一部分」例外訂為 0.5%（鼓勵提升暴擊率）。近戰技能的吸血 ×1.3 與多個來源累加保留。物品數值超過上限時一律以 0.3% 計算，舊存檔也一樣。1% 以下的數值改顯示到小數第二位。

吸血 / 吸魔會嚴重破壞遊戲體驗，訂為硬規則（寫進專案守則並由測試把關）；新版本也受此限制，要往上調必須先提出理由並討論。

v0.3.0：橘 / 紅裝備大擴充0f307ef版本 0.3.0

11 種裝備（劍、斧、弓、法杖、盾牌、頭盔、盔甲、手套、鞋子、戒指、護身符）都擴充到橘 12 件、紅 6 件：橘從 33 件增加到 132 件、紅從 23 件增加到 66 件。新的橘色有一部分取材自地牢裡的怪物（酸液甲蟲、骨刺獵獸、單眼浮體等的造型、配色與招式）；新的紅色對應每 5 層的魔王（墓穴守衛、墮落神官、熔岩巨獸、墮落騎士、蜘蛛女王、深淵魔王、深淵統御者），造型與效果參考魔王，從該魔王的樓層起才會掉落。每一件都有專屬外觀與背包圖示（戒指、護身符的材質、寶石與款式也各不相同）。橘、紅的掉落機率減半。標題畫面的版本改為讀取 package.json（v0.3.0）。

新裝備由 5 個代理平行設計（每個負責 2～3 種裝備、各自的檔案，資料在 src/data/uniqueItems/、外觀在 weapons/uniques/ 與 gear/uniques/），合併後用測試檢查：每種 12 / 6 件、名稱不重複、效果條件都能成立、吸血上限、每件武器的造型與光芒不重複。裝備圖鑑加上遊戲裡的圖示（由 item-icons.js 在網頁上即時產生，避免把幾百張圖塞進 HTML）。

七組連段：Q / W / E / R / A / S / D18197a5存檔 v13

連段從 Q / W / E 三組增加為 Q / W / E / R / A / S / D 七組，每組一樣是三招，依等級解鎖：Q Lv1、W Lv3、E Lv6、R Lv10、A Lv15、S Lv20、D Lv25（每組的第 2、3 格仍是 Lv3、Lv6）。未解鎖的按鍵在技能列顯示為窄格與解鎖等級。新角色改為左鍵重砍、Q 火球，兩個起始技能一開始都能用。按住 Ctrl / ⌘ / Alt 時不切換連段（避免 ⌘R 重新整理時誤觸）。手機版只放 Q / W / E / R 四個按鈕。「輪迴之環」維持 Q → W → E 輪轉，「墮騎之戒」維持 Q / W / E 三種附魔。

存檔改為 v13（舊存檔的三組連段保留，新增四組空的）。按鍵用實體鍵位判斷，不受輸入法影響；R / A / S / D 原本沒有其他用途，開發用快捷鍵也沒有衝突。

v0.4.0 規格：戰術技能與武器規則設計討論

把 10/17～18 的討論（草稿 v01～v03）整理成 SPEC（md 給人看、yaml 給程式對照），再寫成 P0～P9 十個階段的開發計畫。開工前逐條定案 9 個待決事項：左鍵被禁用時灰掉提示、連段有一招被禁用就整組停用、戰術 T4 規則與其他類別相同、所有持續傷害（含燃燒）不吸取、閃光粉 Lv1～2 改為全元素減半、機關數值即時跟隨玩家、機關不受玩家技能波及等。

設計者的決定都回寫 SPEC 的變更紀錄；SPEC 與實作不一致時以「先改 SPEC、再改程式」處理（例如 SPEC 原本寫戰術 T4 要開通次數，定案後改掉）。

武器允許矩陣（扣分改禁用）818394c～9b8cd4f

劍斧＝近戰＋魔法、弓＝遠程＋魔法、法杖＝魔法，新的「戰術」任何武器都能用；魔法對劍斧弓維持 −20%、法杖 +15%。拿錯武器時左鍵不出手、連段整組不施放，頭上浮字說明原因（「法杖無法使用近戰技能」），技能列與技能頁灰掉、劃線；配置保留，換回武器就恢復。武器提示多一行「可用技能」。

檢查只放在玩家的指令入口，怪物共用的技能系統不動；沒拿武器時不限制（新角色起始空手）。

戰術 12 招：身法、機關、投擲9ad5256～9a93c26

新增第五類技能「戰術」：身法（翻滾、影步、鉤索、幻影突襲）、機關（絆索網、霜凍地雷、雷電圖騰、火藥桶）、投擲（淬毒飛刀、霜凍瓶、擲斧、閃光粉）。新狀態中毒（最多 3 層）、流血（每跳可暴擊）、弱化（降低抗性）。機關是有血量的佈置物：血量與防禦跟著玩家、全身最多 2 個，怪物在 3 格內會改打機關，被打壞時地雷與火藥桶會爆炸。新 Combo 規則破綻一擊、乘虛而入、佈雷引爆。

重點

這套做法為什麼有效

  1. 底層規則一開始就定死。座標、更新頻率、隨機種子、模組依賴方向，越晚改越貴，所以最先決定。

  2. 每個系統先做最簡單可用的版本。技能先 4 個、掉寶表先一張、地圖先手畫，全部接通後再逐一加深。

  3. 資料和程式分開。MVP 之後擴充變快，主要靠「新內容只改 src/data/」。

  4. 品質靠自動檢查守住。每個 Milestone 都要通過測試、lint 與依賴檢查，大改多次也沒有失控。

  5. 路線圖可以調整，但要寫回文件。M7.5 的插入與 M8、M9 的順序對調都有記錄。
