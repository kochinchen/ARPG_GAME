樓層區間

地圖以「世界種子 + 樓層」隨機產生，每格 0.5 單位。一般樓層擊敗一定比例的怪物後出口開啟；魔王層要擊敗魔王。

  • 掉寶階級：放大黃以上的稀有度權重（白、藍不變），倍率依序是黃 / 紫 / 橘 / 紅。1 = ×1；2 = ×1.2 / 1.4 / 1.4 / 1.5；3（15～19 層）= ×1.4 / 1.8 / 1.8 / 2；4（20～24 層）= ×1.5 / 3.6 / 3.6 / 2；5（25 層起）= ×1.6 / 4.4 / 4.4 / 2.6。

    每層的首領

    沒有魔王的樓層（1～4、6～9、11～14…26～29 層）都有一隻首領：從該層的怪物池抽一隻，守在出口前約 16 格（出口的安全範圍 12 格之外）。名稱前面有「首領・」，腳下有精英的金色光圈。種類與位置由世界種子決定，讀檔後不變。

    首領強化數值
    HP×6（精英 ×3）
    傷害×2（精英 ×1.8）
    經驗×8
    體型×1.5
    精英詞綴2～3 個（第 1 層起就有）
    樓層減傷第 10 層起，物理與元素都有（精英的數值）
    • 出口：清怪比例達到、而且擊敗首領後才開啟（畫面上方顯示「還需 N 隻＋首領」）。
    • 掉落：首領本身的掉落＋精英掉落表；擊敗後原地出現首領寶箱。
    • 首領寶箱：擲 6 次（一般寶箱 3 次）、必出 1 件裝備；金幣比重 35%、每次 40～100 金幣（一般寶箱 15%、10～30），是金幣的另一個來源。每層只能開一次。
    • 重新進入樓層時首領會重生，但寶箱開過就不會再出現。

      魔王與小王

      HP 降到門檻時進入下一階段。卡片上的「實際約」是出現的第一個樓層套用樓層成長與魔王強化（HP ×1～20、傷害 ×1～4）後的數值；特殊技能的圓形 / 扇形範圍另 ×1.5～3（直線招式不變），下方招式說明是基礎範圍。

      方向
      每張卡片右側是女主角（比例尺）；所有卡片同一個比例，可以直接互相比較。

      模型依遊戲中的碰撞半徑與體型倍率縮放，畫的是基準體型的待機姿勢；遊戲中近戰怪另有隨機體型（平均 ×1.2），精英怪再 ×1.2。高度倍數以正面的最高點計算（含角、翅膀等），四足獸與蟲類是身體的高度。

      資料來源：src/data/enemies.ts、bosses.ts、eliteAffixes.ts、floors.ts、balance.ts 與 game/world/DifficultyScaler.ts，由 DataRegistry 載入後輸出；模型取自 src/render/figure/（依 PolyFigure 的投影與光線輸出）。遊戲內的數值會因四捨五入、隨機體型與裝備而略有差異。
