組合技圖鑑

把三個技能放進同一格連段，依序施放時會依標籤判定是否組成組合技，第三招（部分規則含第二招）得到加成。下面的資料由遊戲的判定程式實際跑過所有排列產生，可以直接拿來測試。

連段試算

組合技規則

規則比對的是技能的標籤（投射物、重擊、元素…），不綁定技能名稱；只有 Tier 1 的秘密組合技指定技能。一組排列只會觸發優先度最高的一條。

判定方式

判定規則

  1. 一定要三招。連段只有一、兩格時照常施放，但不判定組合技。

  2. 同一招連放三次不算。例如火球 → 火球 → 火球。

  3. 距離不能直接來回跳。「近 → 遠 → 近」與「遠 → 近 → 遠」不成立；其他 25 種距離排列都可以。

  4. 優先順序。Tier 小的先；同 Tier 比較條件多寡，條件多的先；再相同就看規則編號。

  5. 近身回報。距離是「近 → 近 → 遠」時，第三招再加傷害 、範圍 ，表格以「＋近身回報」標示。

  6. 組合失敗照常施放。三招一定依序放出，只是沒有加成。某一招沒有目標或魔力不足時整組中斷。
