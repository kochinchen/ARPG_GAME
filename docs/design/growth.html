角色成長與戰鬥模擬

上半部是 Lv1～70 的成長表。下半部有兩個可以點的模擬器：屬性點（HP / MP / 防禦等）與技能點（技能樹與攻擊力），並可測試三段 Combo。所有數值都會拿來跟你選的怪物比較，可以對照怪物頁確認難度。

頁面開啟時載入的是示範配置（Lv30、近戰重擊路線），不是任何存檔的資料。玩家沒有普通攻擊：開局免費送的重砍就是預設左鍵。

剩餘 /

裝備加成（選填）

數值欄填所有裝備加起來的總和：武器基底傷害（劍、斧、弓已乘主倍率）、法術強度（法杖已乘主倍率）＋詞綴。武器種類的內建加成會自動算進去（劍斧弓的魔法 −20%、法杖 +15%）；武器不能用的技能類別會在技能說明與 Combo 測試標出（v0.4.0 武器允許矩陣）；百分比欄只填詞綴，例如「戰士的」「獵手的」「秘法的」與強屬性。預設為空手、無裝備。裝上的 Support 被動（模擬器 2）也會算進來。

融合試算

放 2～4 件裝備（飾品以外：武器 → 攻核、防具與盾牌 → 護核；四件同一類 = 純核，屬性多一條）與 0～2 件飾品，用遊戲的融合判定算出按下融合前就確定的部分：核種、核階、核色、元素、條數、印記機率，以及鑲在各部位的主屬性範圍與費用。數值以紫裝為準；鑲在白 / 藍 / 黃 / 橘裝上再乘 ×0.5 / 0.6 / 0.75 / 1.25。

合成區（飾品以外的裝備）橘 / 紅可以選設計；法杖、頭盔可以選元素詞綴
飾品區（戒指 / 護身符）只提高印記機率
資料與規則取自專案 src/data/ 與 src/game/（MasteryRule、ComboResolver、SkillDescriber 直接打包進本頁）。傷害是期望值估算：不含隨機體型、精英詞綴、樓層抗性、裝備詞綴與傳奇效果。
