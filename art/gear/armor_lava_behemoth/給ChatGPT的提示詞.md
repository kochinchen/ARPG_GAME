# 熔岩巨甲：給 ChatGPT 的設計圖提示詞

附上這個資料夾 `reference/` 裡的 3 種圖：
- `女主角-五視圖.png`：要穿這件盔甲的女主角，畫風和比例的依據
- `熔岩巨獸-魔王.png`：盔甲是從這隻魔王胸口剝下來的
- `現在-*.png`：遊戲裡現在的樣子（程式畫的，很陽春，只參考配色和元素）

分兩次送。第一次先確認設計，滿意後再送第二次，產生給 3D 生成用的四視圖。

---

## 第一次：設計稿（穿在女主角身上）

```
我在做一款等角視角的 ARPG，附圖是女主角的五視圖設定稿，畫風是「細緻的低多邊形」：很多小三角面、每個面一個顏色、沒有寫實貼圖。

請幫我設計一件神話級胸甲「熔岩巨甲」，穿在這位女主角身上，畫一張正面偏右 3/4 角度的全身設計稿。

背景故事：熔岩巨獸胸口剝下的岩殼，裂縫裡的岩漿隨著戰鬥越燒越旺。（附圖有魔王「熔岩巨獸」的樣子，以及遊戲裡現在這件盔甲的陽春版。）

設計重點，請美化並把特色做得更強烈：
1. 材質是深色火山岩板（深棕到黑），像魔王身上的岩塊，一片一片疊成胸甲，邊緣粗糙、有稜角。
2. 岩板之間的裂縫透出發光的岩漿（橘紅到亮黃），裂縫像肋骨一樣從胸口往兩側延伸。
3. 胸口正中央鑲一顆發光的「熔核」（岩漿核心），是整件盔甲的視覺焦點。
4. 兩肩是大塊的岩石護肩，上面有幾根尖刺，比魔王小得多，但輪廓要一眼看出是同一種生物。
5. 要讓人感覺「很重、很硬」，但還是合身的女性胸甲，不要變成一整個大箱子。從等角俯視的遠距離也要能一眼認出輪廓。
6. 只設計胸甲和護肩。女主角的其他部分（頭髮、臉、手套、腰帶、裙子、靴子）維持原設計不要改。
7. 保持和附圖一樣的低多邊形小三角面畫風，配色以深岩色為主、岩漿色點綴。
```

## 第二次：給 3D 生成用的四視圖（設計確定後）

```
很好，就用這個設計。請另外畫 4 張圖，用來給 3D 生成模型（微軟 TRELLIS）當輸入：

- 只有胸甲和護肩，像掛在隱形的人體上展示，裡面是空的；不要畫人、頭、手臂、腰帶或其他裝備。
- 4 張分開的圖，每張一個角度：正面、右側面、背面、左側面。
- 正交視角（沒有透視），4 張的大小、高度、位置完全一致，盔甲置中、佔畫面約 80%。
- 純白背景，沒有地面、陰影、文字、標註或光暈特效（岩漿用發光的「顏色」表現就好，不要有向外擴散的光）。
- 光線均勻、從正面打過來，不要強烈的明暗對比。
- 保持同樣的低多邊形小三角面畫風和配色。
```
