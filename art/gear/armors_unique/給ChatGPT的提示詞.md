## 第一段：橘色 4 種基本款

```
我在做一款等角視角的 ARPG，畫風是「細緻的低多邊形」：很多小三角面、每個面一個顏色、沒有寫實貼圖。第 1 張附圖是女主角的五視圖；第 2 張是之前你幫我設計的神話胸甲「熔岩巨甲」，第 3 張是它做進遊戲後穿在女主角身上的樣子。請沿用同樣的畫風和穿法（胸甲＋肩甲＋腰部垂甲，包住上半身，露出手臂與腿）。

請設計四種「傳奇（橘色）盔甲的基本款」，之後 12 件橘甲都從這四種延伸（換配色和小零件）。畫成一張設計稿：四件盔甲分別穿在女主角身上、正面站姿、左右並排，下方用中文標名稱。純淺色背景。四種的「輪廓」要一眼就分得出來。

A「晶岩重甲」：黑曜石與岩塊拼成的厚重胸甲，肩上是大塊的岩石肩甲，岩縫裡透出熔岩或礦物的光（示範：熔岩橘）。沉重、堅不可摧。
B「甲殼鱗甲」：甲蟲殼、鱗片與獸角層層疊成的胸甲，線條有機彎曲，肩甲像甲殼或鱗片翻起，胸口一塊硬殼。野性。（示範：酸綠甲殼）
C「元素法袍」：合身的上衣加長長的下擺（到膝蓋），肩上有尖角飾片，胸口一顆元素寶石，袍上有流動的發光紋路（示範：星光藍紫）。輕盈、華麗。
D「倒刺輕甲」：皮甲或鎖子甲為底，肩甲、胸口和手臂外側長著一排倒刺或骨刺，腰部有皮帶與小護片。輕便、危險。（示範：骨白配深褐）

共同要求：
1. 盔甲穿在女主角身上，比例照第 1 張；不要畫武器。
2. 遊戲是等角俯視、畫面很小，所以輪廓最重要（尤其肩甲和下擺）；小細節是放大才看得到的加分。
3. 發光的部分用明亮的顏色表現，不要畫向外擴散的光暈。
4. 保持低多邊形小三角面的畫風。
```

## 第二段：紅色 6 件

```
接著請用同樣的畫風，設計六件「神話（紅色）盔甲」，每一件都是獨一無二的造型，彼此的輪廓要完全不同，而且都要比橘色的更大、更華麗、更有壓迫感。畫成一張設計稿：六件分別穿在女主角身上、正面站姿、並排，下方用中文標名稱。純淺色背景。

1「熔岩巨甲」：就是第 2、3 張附圖的那件，請照原本的造型畫（黑岩甲殼、熔岩裂縫、胸口熔核、巨大岩石肩甲）。
2「深淵甲殼」：深淵巨獸蛻下的殼，深紫黑的甲殼一片片包住上身，肩上翻起尖銳的殼刺，甲殼縫隙透出紫光。
3「不朽者」：倒下七次又站起來的戰士鎧甲，古老的金色板甲布滿修補過的裂痕，胸口一顆發光的不滅心核，背後一圈殘破的光環。
4「墮騎黑鎧」：被黑暗吞噬的騎士板甲，黑鐵配暗紅，胸甲上三道光溝分別是紅、藍、黃（火、冰、雷），肩甲是尖角。
5「蛛后絲甲」：蜘蛛女王的絲織成的軟甲，紫黑色、貼身，胸口與肩上有蜘蛛腳般的尖骨，身上纏著發光的綠色蛛絲，腰間掛著小卵囊。
6「統御者魔鎧」：深淵統御者的甲殼，暗金與黑紅，巨大的王冠形肩甲，胸口一個日蝕般的黑色圓盤外圈發光，下擺像撕裂的披風。

共同要求同上：穿在女主角身上、不畫武器、發光的部分用明亮的顏色表現（不畫光暈）、低多邊形小三角面、輪廓一眼就能分辨。
```

## 第三段：每件單獨一張（盔甲獨立成物件，正面 / 背面 / 3/4）

晶岩重甲和熔岩巨甲太像，改成「黑曜晶甲」：光滑的黑曜石板、銳利晶體切面、冷色礦物光，不用粗岩與橘色熔岩。

每張的共同句子：

```
請把「{名稱}」單獨畫成一件盔甲物件：不穿在人身上、沒有人體，像遊戲道具的設計稿。同一張圖並排畫正面、背面、3/4 側面三個角度，純淺色背景，下方用中文標名稱。只畫胸甲、肩甲與腰部垂甲（不含頭盔、手套、靴子），尺寸照女主角的身材。畫風同前面（細緻的低多邊形、發光部分用明亮的顏色、不畫光暈）。造型：{造型}
```

造型依序：
- 橘 A 黑曜晶甲（取代晶岩重甲）：光滑如玻璃的黑曜石板拼成的胸甲，邊緣是銳利的晶體切面，縫隙透出冷色的礦物光（青藍），肩上是一簇簇往上長的黑晶柱，胸口一塊大晶核；和熔岩巨甲要明顯不同，不要粗糙岩塊、不要橘色熔岩裂縫。
- 橘 B 甲殼鱗甲、C 元素法袍、D 倒刺輕甲：沿用第一段的描述與設計稿。
- 紅 1～6：沿用第二段的描述與設計稿。
