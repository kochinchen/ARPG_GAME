# 劍的 TRELLIS 底稿：給 ChatGPT 的提示詞

用途：一般劍 T1～T8 不必每把都生成。只生成一把「中性的單手長劍」當底稿，交給 TRELLIS 產生 3D。之後由程式依各階級的 `SwordSpec` 變形與換色（做法同斧頭的 `TrellisAxes.ts`）：
- 刃身：長短、寬窄，以及直刃、寬刃、鋸齒、裂刃。
- 護手：一字、上翹、荊棘、爪、翼。
- 柄頭：圓球、寶石、尖刺、骷髏。
- 顏色：鐵、鋼、黑鋼、血鋼、古金、深淵。

所以底稿要「乾淨、零件分明、沒有花紋」。符文、寶石、發光由程式加。

開一段新對話，附上 `reference/` 的兩張圖：
- `女主角-五視圖.png`：畫風與比例尺。
- `風格參考-三種基本款劍.png`：之前設計的橘劍，用來對齊畫風，不照抄造型。

分兩次送：第一次確認設計，第二次才產生給 TRELLIS 的視圖。

## 第一次：設計稿

```
我在做一款等角視角的 ARPG，畫風是「細緻的低多邊形」：很多小三角面、每個面一個顏色、沒有寫實貼圖（第 1 張附圖是女主角五視圖，當畫風與比例尺；第 2 張是之前設計的劍，請沿用同樣的畫風，但不要照抄造型）。

請設計一把「普通的單手長劍」，之後會拿去生成 3D 模型，再用程式改出 8 個等級的劍（換長短、寬窄、護手、柄頭和顏色），所以要的是一把乾淨、標準、零件分明的劍。請畫一張劍身垂直、劍尖朝上、正面朝向鏡頭的設計稿，旁邊小一點畫同一把劍的側面（看得到刃的厚度）。

設計重點：
(1) 劍身：筆直的雙刃，寬度中等偏寬（像騎士長劍，不是細劍）。從護手到劍尖寬度幾乎不變，最後三分之一才收成尖。中央有一道清楚的血槽，兩側有斜磨的刃面。刃要有明顯厚度，側面看是菱形斷面，不要薄得像紙。
(2) 護手：一字形橫擋，粗而厚，兩端微微上翹並略為加粗，寬度約劍身寬的 3 倍；中央有一塊包住劍根的方形護片。
(3) 握柄：皮革纏繞，長度約一個半拳頭，和護手、柄頭清楚分開。
(4) 柄頭：粗壯的多面體圓球（像切面的球），不要尖刺或寶石。
(5) 顏色：劍身是中性的鋼灰色，用明暗表現斜面、血槽與刃緣（刃緣最亮）；護手與柄頭是暗鐵色；握柄是深棕色皮革。不要金色、不要寶石、不要符文、不要發光、不要血跡或缺口。
(6) 整把劍長約女主角腳踝到胸口。所有零件都要粗、厚、彼此黏接，不要細尖刺、細鏈子、垂飾或飄帶。
(7) 保持低多邊形小三角面畫風，不要大平面；純白背景，沒有陰影、文字、標註或光暈。
```

## 第二次：給 3D 生成用的視圖（設計稿確認後）

TRELLIS 用多圖模式（`trellis-community/TRELLIS`）。ChatGPT 擠在一張圖裡會變形，所以分兩張畫，再切成 `multiview/front.png`、`multiview/side.png`（必要時再加 `multiview/three-quarter.png`）。

```
很好，就用這個設計。接下來要給 3D 生成模型（微軟 TRELLIS）當輸入，請生成一張圖：這把劍的「正面」，劍身垂直、劍尖朝上，置中，上下留白。 (1) 只有劍本身，不要女主角、手、劍鞘、地面或特效。 (2) 正交視角（沒有透視）、視線水平，劍完全正對鏡頭，左右對稱。 (3) 劍的上下兩端都完整入鏡，劍尖與柄頭不可切到。 (4) 刃的斜面、血槽和刃緣用明暗清楚分開；護手、握柄、柄頭各自是分明的一段。 (5) 純白背景，沒有陰影、文字、標註或光暈；光線均勻、從正面打過來。 (6) 保持同樣的低多邊形小三角面畫風和配色。
```

```
再生成一張圖：同一把劍的「正側面」（轉 90 度，看刃的厚度），劍身垂直、劍尖朝上，置中。規則和上一張完全相同：正交視角、視線水平、整把入鏡、純白背景、沒有陰影或文字。長度、比例、配色和上一張一致，劍尖與柄頭的高度對齊上一張。側面要看得出刃的菱形斷面厚度、護手的厚度與上翹，以及柄頭是圓球。
```

如果 TRELLIS 生成的刃太薄或破洞，再補一張：

```
再生成一張同一把劍的 3/4 角度圖（從正面往右轉約 45 度、視線水平），規則同上，讓刃的斜面和厚度更清楚。
```
