# 橘紅弓的三種基本款：給 ChatGPT 的提示詞

附上 `reference/` 的三張圖：
- `女主角-五視圖.png`：畫風（細緻的低多邊形）與比例。
- `風格參考-熔岩巨甲設計稿.png`：上次 ChatGPT 畫的神話胸甲，畫風要一致。
- `現在的橘紅弓.png`：遊戲裡現在的樣子，每一把都只是換顏色的細木條，要整個重新設計。

三種基本款是之後 18 把橘紅弓共用的骨架，每一把再依名稱換材質、配色與小零件：

| 基本款 | 會用到的弓 |
|---|---|
| A 獸材弓（怪物素材做的） | 骸骨長弓、骨刺獵弓、酸蝕長弓、暗豹獵弓、獨眼雷弓、霜孢長弓、火囊爆弓、纏絆長弓 |
| B 精工元素弓（精緻反曲弓 + 元素） | 追風者、風暴之眼、獵影者、先機長弓、天穹裂弦（紅）、群星箭雨（紅） |
| C 魔王神弓（魔王素材熔鑄） | 血祭神弓、墮騎魔弓、蛛后毒弓、魔王炎弓（皆為紅） |

```
我在做一款等角視角的 ARPG，畫風是「細緻的低多邊形」：很多小三角面、每個面一個顏色、沒有寫實貼圖（第 1、2 張附圖是女主角和一件神話胸甲的設計稿，請沿用同樣的畫風）。第 3 張附圖是遊戲裡現在的傳奇（橘）與神話（紅）弓，每一把都只是換顏色的細木條，太單調，要重新設計。

請設計三種「橘 / 紅專用的基本款弓」，之後 18 把橘紅弓都會從這三種延伸（換材質、配色和小零件）。畫成一張設計稿，三把弓左右並排、弓弦朝右、垂直擺放，每把旁邊再加一個小的 3/4 角度，下方用中文標名稱。純淺色背景、不要人物。

A「獸材弓」：用怪物的骨節、甲殼、脊骨拼成的有機弓臂，關節處用皮繩和金屬箍綁住，弓梢是彎鉤或爪；輪廓不規則、很野性。示範配色：骨白與暗褐。
B「精工元素弓」：精緻的反曲弓，弓臂是流線的金屬或硬木，中段兩側嵌著發光的元素晶體，弓梢像羽翼或刀鋒；弓弦可以是一道細細的能量光。示範配色：銀白與淡藍光。
C「魔王神弓」：用魔王的翼骨或折斷的劍熔鑄成的巨大長弓，比 A、B 更大、更有壓迫感：弓臂上有尖刃與倒刺，握把上方嵌一顆發光的核心，弓臂外緣有裂縫透出光。示範配色：黑鐵與熔紅光。

共同要求：
1. 弓的長度大約是女主角從腳踝到頭頂，握把在中央，左右（上下）大致對稱，拿在手上不會擋住身體。
2. 遊戲裡是等角俯視、畫面很小，所以三把的「輪廓」要一眼就分得出來；小細節是放大時才看得到的加分。
3. 發光的部分用明亮的顏色表現，不要畫向外擴散的光暈。
4. 保持低多邊形小三角面的畫風。
```
