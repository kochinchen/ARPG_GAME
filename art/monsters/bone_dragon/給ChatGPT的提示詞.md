# 骨龍：給 ChatGPT 的提示詞

設計者 2026-11-02 定案：用骷髏戰士、重甲骷髏、墮落聖殿騎士的物件組成的四足龍型腐化怪，怨念的集合體。大小參考結晶獸（女主角 ×2.26）。

兩種屬性每次出現時隨機抽，發光區塊依抽到的順序上色。設計稿用「亮橘」和「青藍」兩個固定顏色標出第一、第二區塊，之後依顏色分區、在遊戲裡換色。

附上 `reference/` 裡的圖：`skeleton.png`、`armored_skeleton.png`、`fallen_templar.png`、`女主角-五視圖.png`、`結晶獸-大小參考.png`。

設計者追加（2026-11-02）：要更恐怖，全身就是一張超大的嘴巴。沒有獨立的頭和脖子，身體橫向裂成巨口，上顎是背甲、下顎是腹部，肋骨變成牙齒，嘴裡塞滿骷髏頭與骨手；下面第一次提示詞第 1、2、3 點以這段為準。

設計者再追加（2026-11-02）：嘴巴占身體絕大部分，四根觸手（骨節組成，尖端是小嘴），下面四隻腳，移動緩慢，沒有尾巴。設計者給的參考圖是市售怪獸公仔，只取結構，不上傳給 ChatGPT，也不照著畫。

設計者確認定稿（`concept/巨口觸手設計稿-定稿.png`）後，四視圖另外要求：嘴巴張到最大，上下牙尖完全不碰、中間至少留身體高度三分之一的空隙，避免 TRELLIS 把嘴縫起來；側面要看得到楔形開口；光環用骨柱固定在上顎，不要漂浮。

分兩次送：先確認設計稿，滿意後再產生四視圖。四個角度擠在一張圖會被壓窄，所以分「正面＋背面」「右側＋左側」兩張。

## 第一次：設計稿

```
我在做一款等角視角的 ARPG，畫風是「細緻的低多邊形」：很多小三角面、每個面一個顏色、沒有寫實貼圖（附女主角五視圖當畫風與比例尺）。

請設計隱藏魔王「骨龍」，畫一張正面偏右 3/4 角度、稍微俯視的全身設計稿，旁邊站著女主角當比例尺。

背景：地牢裡死去的士兵與騎士的怨念聚在一起，把他們的骨頭和盔甲拼成一條龍。牠不是一隻龍死後的骨骸，而是很多具屍骸組成的集合體。

附圖說明：
- skeleton：骷髏戰士，取牠的骷髏頭和骨頭。
- armored_skeleton：重甲骷髏，取牠的厚重板甲與頭盔。
- fallen_templar：墮落聖殿騎士，取牠的黑金板甲、碎裂的光環與塔盾。
- 結晶獸：體型參考，骨龍和牠差不多大，是粗壯矮壯的大型四足獸，不是瘦長的龍。

設計重點：
1. 四足步行、四隻腳都踩在地上、低伏粗壯；腿粗、身體厚實、脖子短而粗、頭大。沒有翅膀。粗短的尾巴。
2. 頭骨是龍的形狀，嘴微微張開，看得到牙齒和嘴裡的光。頭上戴著破損的重甲頭盔碎片和碎裂的光環。
3. 身體用大塊、形狀清楚的物件拼成：肩膀和背上是重甲骷髏的厚板甲，側腹鑲著聖殿騎士的塔盾，胸腔是粗肋骨組成的大籠子，裡面塞著許多人類骷髏頭。
4. 不要細鎖鏈、細長尖刺、細骨頭、薄布條；所有物件都要粗、厚，彼此黏在一起，輪廓緊實。
5. 配色：灰白骨色 + 深灰鐵色 + 黑金板甲。
6. 發光分成兩個區塊，顏色要純、要亮，彼此不要混在一起：
   - 第一區塊（亮橘色）：眼睛、嘴裡、胸腔裡面。
   - 第二區塊（青藍色）：背脊沿線的裂縫、尾巴、四隻腳的關節縫。
7. 保持低多邊形小三角面畫風，不要大平面；不要背景、場景、特效、文字。
```

## 第二次：給 3D 生成用的四視圖（設計確定後，兩張分開送）

```
很好，就用這個設計。請畫給 3D 生成模型（微軟 TRELLIS）用的圖。
這張圖左右並排畫同一隻骨龍的「正面」和「背面」：
(1) 正交視角、視線水平；兩隻大小、高度完全一致，各自置中，不要被壓窄，體型維持粗壯。
(2) 中立站姿：左右對稱、四隻腳平均站穩、頭朝正前方、尾巴往正後方；不要攻擊動作。
(3) 四隻腳之間、腳與身體之間留空隙。
(4) 不要女主角、地面、特效；純白背景，沒有陰影、文字或光暈（發光部位只用純亮橘和純青藍的顏色表現）；光線均勻、從正面打過來。
(5) 保持同樣的低多邊形小三角面畫風和配色。
```

```
同樣的規格，再畫一張：左右並排畫同一隻骨龍的「右側面」和「左側面」，大小、高度和上一張一致，不要被壓窄。
```
