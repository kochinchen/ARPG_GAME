# 蜘蛛女王：給 ChatGPT 的設計圖提示詞

附上這個資料夾 `reference/` 裡的 2 種圖：
- `女主角-五視圖.png`：遊戲女主角，畫風和比例的依據（女王的人形上半身要比她高大）
- `現在-*.png`：遊戲裡現在的蜘蛛女王（程式畫的，很陽春，只參考配色和元素）；4 張是 左前 / 正面 / 右前 / 背面

分兩次送。第一次先確認設計，滿意後再送第二次，產生給 3D 生成用的四視圖。

---

## 第一次：設計稿

```
我在做一款等角視角的 ARPG，附圖是女主角的五視圖設定稿，畫風是「細緻的低多邊形」：很多小三角面、每個面一個顏色、沒有寫實貼圖。

請幫我設計第 25 層的魔王「蜘蛛女王」，畫一張正面偏右 3/4 角度、稍微俯視的全身設計稿，旁邊站著附圖的女主角當比例尺。

背景故事：上半身為人形、下半身為巨蛛的深淵女王。噴射毒液、吐出蛛網，並不斷產下蜘蛛；受傷後召喚蜘蛛群圍攻。（附圖有遊戲裡現在這隻魔王的陽春版，只參考配色和元素。）

設計重點，請美化並把特色做得更強烈：
1. 下半身是巨大的蜘蛛：紫黑色甲殼（深紫到黑，邊緣有較亮的紫色稜線），身體抬得很高，八隻細長、帶刺的腳往外撐開，腳尖是螢光綠的水晶利刃，腳的關節是發光的綠色圓珠。
2. 大而飽滿的腹部在後方，背上有螢光綠的菱形花紋和兩排尖刺，末端是毒針。
3. 從蜘蛛前方長出人形的女王上半身（腰部以上）：淡紫灰的皮膚、深色鮑伯頭、發光的綠色眼睛、頭頂一圈紫色尖刺冠（正中一根綠水晶）、胸前綠水晶墜飾、肩膀周圍一圈尖刺領。
4. 雙臂末端是鐮刀狀的長爪（甲殼材質，像螳螂或蜘蛛的前肢），不是人手。
5. 配色：紫黑甲殼為主、螢光綠（毒液）點綴，綠色只用在發光的部位（眼睛、關節、腳尖、花紋、水晶）。
6. 要有魔王的壓迫感：上半身比女主角高大，整隻的寬度約女主角身高的 2.5 倍。從等角俯視的遠距離也要一眼認出「人形 + 巨蛛」的輪廓。
7. 保持和附圖一樣的低多邊形小三角面畫風；不要畫蜘蛛網（遊戲裡另外用特效畫）。
```

## 第二次：給 3D 生成用的四視圖（設計確定後）

```
很好，就用這個設計。請另外畫 4 張圖，用來給 3D 生成模型（微軟 TRELLIS）當輸入：

- 只有蜘蛛女王本身，不要女主角、蜘蛛網、地面或其他東西。
- 4 張分開的圖，每張一個角度：正面、右側面、背面、左側面（側面是身體正對畫面左右，看得到 8 隻腳的側面排列）。
- 正交視角（沒有透視），視線水平、不要俯視；4 張的大小、高度、位置完全一致，魔王置中、佔畫面約 80%。
- 姿勢是中立的站姿：左右對稱、8 隻腳平均撐開踩在同一個水平面上、雙臂鐮爪自然垂在身體前方兩側，不要做出攻擊動作（之後要綁骨架做動畫）。
- 腳比設計稿稍微粗一點（太細的部位 3D 生成會斷掉），腳與腳、爪與身體之間要留空隙，不要互相重疊黏在一起。
- 純白背景，沒有陰影、文字、標註或光暈特效（發光部位用亮綠的「顏色」表現就好，不要有向外擴散的光）。
- 光線均勻、從正面打過來，不要強烈的明暗對比。
- 保持同樣的低多邊形小三角面畫風和配色。
```
