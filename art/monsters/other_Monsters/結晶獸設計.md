# 結晶獸：火、冰、雷、毒

**設計者 2026-11-01 定案（取代下面的出現樓層、權重與血量）：專門噴錢的怪。** 第 5 層起，每次進入樓層（新樓層或回到上一層）30%、25%、20%、15%、10%、5% 各自擲一次，中幾個就出現幾隻（平均約 1.05 隻）；讀檔不重擲。單獨行動；打倒掉 400～1500 金幣（第 1 層到第 35 層線性增加，±10%，分 6 堆），不算進開出口的擊殺數；血量、傷害、經驗和樓層減傷與精英相同，但沒有詞綴、光圈與精英掉落；大小固定，與震地獸同高（女主角 ×2.26）。死亡 0.8 秒後晶核碎裂（EnemyDef.onDeath）。規則在 `balance.goldWalker`。


設計稿：`concept/四屬性設計稿-1.png`（ChatGPT，以 `Stone_Walker_.png` 為參考）。
數值都是第一版，放進遊戲後要跑 `npm run balance` 與實際試玩再調。

## 素材檢視：Stone_Walker_.glb

- 20,850 面、15,512 頂點；沒有骨架與動畫；寬 1.0、高 0.83、深 0.67。
- 可用：大猩猩般的輪廓，遠距離也好認；手臂與軀幹之間有空隙，適合綁骨架。
- 要處理：
  - 貼圖烤死了光影（過曝、橘色與藍色邊光），顏色不能直接用。
  - 拳頭比腳底低約 3 公分，貼地計算會以拳頭為準，腳會浮起來。
  - 臉部模糊；單圖生成，背面與左右兩側不對稱。
  - 減到 1100 面已經變成大平面（實測），不符合密集小三角面的要求。

| | 熾晶獸（火） | 霜晶獸（冰） | 雷晶獸（雷） | 毒晶獸（毒） |
|---|---|---|---|---|
| 出現樓層 | 15 | 18 | 21 | 13 |
| 定位 | 壓迫：逼你離開原地 | 控場：拖慢、卡位 | 突襲：忽遠忽近 | 消耗：地面越來越髒 |

### 招式（都能用現有效果做）

**熾晶獸**
- 灼拳（普攻）：火焰傷害 + 燃燒 2 秒。
- 熔晶噴發：前搖 1.2 秒、地面提示、冷卻 8 秒；目標附近 3 處依序噴發（半徑 1.1，倍率 0.9），每處留下 3 秒的燃燒地面。

**霜晶獸**
- 凍拳（普攻）：冰寒傷害 + 緩速 25%、2 秒。
- 冰晶列：前搖 1.0 秒、冷卻 10 秒；在目標腳下排出 5 段、與施放方向垂直（spacing 1.2）。落下瞬間冰凍 0.8 秒，之後留 4 秒的緩速 40% 區域。不擋路，只是減速區。

**雷晶獸**
- 雷拳（普攻）：閃電傷害，攻速 0.9。
- 雷晶突進：前搖 0.8 秒、地面提示、冷卻 7 秒；直線衝 5 格，終點範圍傷害 + 暈眩 0.6 秒。看提示可以閃開。
- 落雷：前搖 1.0 秒、冷卻 9 秒；目標附近 3 處依序落雷（半徑 0.9），打中才有傷害。

**毒晶獸**
- 腐拳（普攻）：毒素傷害 + 中毒，最多疊 3 層。
- 毒泡投擲：前搖 0.9 秒、冷卻 7 秒；拋出毒泡（距離 7，落地也會破），留下半徑 1.3、5 秒的毒區。
- 毒痕（被動）：戰鬥中每走 2 格留一小灘 4 秒的毒液。

### 死亡：晶核碎裂

死亡 0.8 秒後原地發動，地面先有提示；給近戰一點風險，也讓死亡有表現。

- 火：半徑 2 爆炸。
- 冰：環狀射出 8 根冰刺，命中緩速。
- 雷：半徑 2 放電，不暈眩（避免死後還被定身）。
- 毒：留下 5 秒毒霧。

資料在 `EnemyDef.onDeath`（技能、延遲、地上提示的半徑）。

## 動作

骨架約 14 根：骨盆、腰、胸、頭、左右上臂 / 前臂 / 拳、左右大腿 / 小腿 / 腳。背上的結晶跟著胸。

| 動作 | 設計 |
|---|---|
| 待機 | 雙拳撐地、肩膀隨呼吸緩慢起伏，偶爾低頭左右看 |
| 行走 | 指節行走：左拳配右腳、右拳配左腳交替撐地，身體重心左右晃，步伐沉重 |
| 普攻 | 單拳舉到肩上 → 砸向前下方 → 拳頭貼地停一拍（給玩家還手的空檔） |
| 受傷 | 上身微微後仰，幅度小，表現很重 |
| 死亡 | 往前撲倒，拳頭鬆開 |
| 熔晶噴發 | 雙拳高舉 → 同時砸地 |
| 冰晶列 | 單拳貼地，往前橫掃推出 |
| 雷晶突進 | 低身蓄力、後腳蹬地 → 雙拳在前撞擊 |
| 落雷 | 上身挺起、雙拳舉高，電光聚在背上晶尖 |
| 毒泡投擲 | 弓背聳肩 → 背部猛然前彎，把毒泡從背上甩出 |

## 製作流程（建議）

四隻各生成一次，因為結晶形狀不同，只換顏色分不出來。

1. 以設計稿請 ChatGPT 畫四視圖（正面＋背面、右側＋左側分兩張，避免被擠窄），雙拳要踩在與腳同一高度。
2. TRELLIS 四視圖模式生成，每隻一次（共 4 次額度）。
3. `monster_ai.py` 減面、綁骨架，共用同一套關節與動作。
4. 減面目標先試約 2500 面，保留小三角面；這幾隻出現比例低，負擔較小，要實測 FPS 再定。
